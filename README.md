# Gaussian Elimination

This project provides an [Elm][elm] library that can perform
[Gaussian Elimination][wikipedia:gaussian-elimination] process on a matrix.

## Concept

[Gaussian Elimination][wikipedia:gaussian-elimination] is

> an algorithm for solving systems of linear equations. It consists of a
> sequence of row-wise operations performed on the corresponding matrix of
> coefficients.

Our implementation allows the matrix to contain elements from an arbitrary
field, for which the field operations should be provided.
